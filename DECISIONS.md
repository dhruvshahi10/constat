# DECISIONS.md (append-only)

- 2026-08-08 — Gates enforced in code, not prompt. Rejected: prompt-only guardrails (unauditable, drafter-dependent). Consequence: MockDrafter and AnthropicDrafter share identical safety posture.
- 2026-08-08 — Contradiction detection via declared frontmatter assertions (`assert.<key>`). Rejected for v0: NLI/semantic contradiction (non-deterministic, untestable as a hard gate).
- 2026-08-08 — Lexical retrieval for v0. Rejected: embeddings-first (opaque scoring; retrieval misses must fail closed anyway, and one deliberate miss (IVS-01.1) is kept in the demo as proof).
- 2026-08-08 — Cert-class claims require source type certificate/attestation even when a truthful "no" exists. Rationale: negative certification answers have deal consequences; phrasing belongs to a human (blueprint p.12).
- 2026-08-08 — Audit log = hash-chained JSONL over SQLite/DB. Rationale: tamper-evidence demoable in one pytest; DB adds nothing at this scale.
- 2026-08-08 — Demo auto-approval only for gate-clean complete-coverage drafts, explicitly labeled SIMULATED in log + report. Rejected: silent auto-approval (misrepresents the human-gate design).
- 2026-08-08 — Default live drafter = Haiku 4.5; gates make the cheap model safe. TRUSTOPS_MODEL env overrides.
- 2026-08-08 — Added GeminiDrafter as the $0 live option: Gemini free tier verified alive (no card, ~10 req/min — covers 24-question runs), OpenAI has no ongoing free API tier, Groq is the fallback alternative. Implemented over raw REST with stdlib urllib — rejected the google-genai SDK (needless install for one endpoint). Same system contract, same fail-closed parse, same gates. GEMINI_API_KEY / GEMINI_MODEL envs.
- 2026-08-08 — Client UI = zero-dependency stdlib web console (ui/app.py, one file, reuses the run-report design system). Rejected for v0: Streamlit review queue (extra install, heavier; stays Phase 2 per docs/TRUSTOPS_V0.md). The console is a thin client over the same pipeline the tests exercise — no separate answer path.
- 2026-08-08 — API keys via git-ignored .env (stdlib loader, re-read per request so a pasted key applies on page refresh). Rejected: python-dotenv (install for 20 lines) and shell exports (hostile to non-technical users). Keys are never logged and never committed.
- 2026-08-24 — Renamed the product TrustOps → **Pramana**; the Python package stays `trustops`. Rejected: renaming the package, because it would edit the import lines in `tests/test_gates.py`, the one file feature work may not touch. A cosmetic alias package was also rejected as noise. The module path is frozen by the constitution and that is documented in the README rather than worked around.
- 2026-08-24 — Questionnaire layout is **detected**, not configured. `export.detect_layout` resolves header row and column roles from header semantics, scored per candidate row. Rejected: a per-client YAML mapping (setup burden on the operator for every new buyer file) and asking the model to find the columns (non-deterministic, and a wrong guess silently ingests zero questions). The demo workbook must resolve to the historical constants or T6 fails, which is the regression test for the detector.
- 2026-08-24 — Ingestion **never auto-assigns `certificate` or `attestation`**. They are the only types satisfying the certification gate, so a keyword match must not be able to hand that key over. A likely certificate is typed conservatively and flagged for a human. Rejected: confidence-scored typing (a 0.9 is still a guess about the field with the largest blast radius). Also: filename evidence beats body prose, and `roadmap` is matched before every other type.
- 2026-08-24 — `AnswerStatus` replaces confidence-score thinking, derived in code by `gates.answer_status()` from citations that survived the gates. Rejected: exposing a numeric confidence, which invites shipping a 0.72. Added `HUMAN_AUTHORED` so a reviewer-written answer is visibly not evidence-backed in the contract and in the delivered workbook.
- 2026-08-24 — Human review **extends the run's own hash chain** (`AuditLog(resume=True)`). Rejected: a separate review log, which would let the two be reconciled after the fact and independently forged. Consequence: `AuditLog.__init__` no longer unconditionally truncates.
- 2026-08-24 — `approve` is unavailable when the gates released nothing. A reviewer who wants to answer anyway must `edit`. Rejected: letting a human approve an empty answer, which would make approval a way to manufacture evidence and would defeat the entire pipeline.
- 2026-08-24 — Trust page publishes **only `EVIDENCE_BACKED`** answers. Rejected: publishing `PARTIAL` and `REQUIRES_HUMAN` with a caveat — an unsigned answer on a public trust page is a representation nobody made, and a thin corpus would produce a page full of hedged claims.
- 2026-08-24 — `CERT_PAT` matches certification schemes by **shape, not by an allowlist of names**. The allowlist did not know ISO 42001, so a roadmap satisfied an ISO 42001 certification question on our own trust page. Any ISO/IEC number now matches, plus a wider scheme set. An unknown scheme costs an unnecessary evidence-class check; a missing one costs a false certification claim to a buyer.
- 2026-08-24 — Added `gates.scope_flag()`: a question naming another workspace, or asking about the system's own configuration, is refused pre-draft. Structural isolation stops another tenant's *documents* being retrieved; it does not stop the engine answering "what does Globex's policy say?" out of this tenant's corpus and attributing one company's controls to another. Accepted cost: a buyer whose company name matches another client's gets a refusal and a human. Fail-closed and noisy beats silent re-attribution.
- 2026-08-24 — Accuracy publishes **two numbers plus an uncited-release count**, never one "hallucination rate". Refusing everything scores 100% on refusal; answering everything scores 100% on citation. Over-release (answered where refusal was required, but with a valid citation) and uncited release (the actual release gate) are different failures and are counted separately. Labels were fixed before the first run and are not revised to match results; retrieval misses are published as failures.
- 2026-08-24 — The eval harness writes its own results into Pramana's evidence corpus as `RPT-EVAL-ADVERSARIAL`, typed **`report`**. Rejected: hand-writing the document (drifts from the numbers) and typing it as an attestation (an evaluation report is not one, and the system must not treat its own results as a certification).
- 2026-08-24 — Public site is **generated by the engine**; a page that cannot be produced from real output is not published and its nav link does not appear. Rejected: hand-written marketing copy with numbers pasted in, which is precisely the failure mode the product argues against.
- 2026-08-24 — Hosted demo runs the **deterministic drafter only**. Rejected: exposing the free-tier Gemini key (free-tier terms permit provider-side use of inputs, so the trust page would have to disclose that visitor questions train a third-party model) and an opt-in toggle (rate limiting and abuse guard cost more than the demo is worth). Live-model runs ship as dated artifacts.
- 2026-08-24 — `vercel.json` uses explicit `builds`. Zero-config detection reads this repo as a single Python app and demands one entrypoint; the project is a static site plus two functions. Also: no root `requirements.txt` (it is what triggers the detection) — dev deps live in `requirements-dev.txt`, function deps in `api/requirements.txt`.
