01The part others get wrong

Most tools answer confidently.
This one refuses correctly.

A wrong answer in a security questionnaire is a material misrepresentation in an enterprise deal. Accuracy percentages concede a remainder that ships anyway. Our release rule is different: zero unsupported claims, enforced in code. These four traps are planted in every eval run, and the suite blocks release if any of them leaks.
