# GOTCHAS.md (append-only)

- 2026-08-08 — bash_tool runs /bin/sh: brace expansion silently creates a literal `{a,b}` directory. Use explicit mkdir paths.
- 2026-08-08 — openpyxl writes formulas with no cached value; recalc via LibreOffice before anything reads data_only. Delivered XLSX must be recalced too.
- 2026-08-08 — Merged cells: only the anchor cell is writable; export must never touch row 1.
- 2026-08-08 — Second-order quarantine: contradicted retention policy correctly killed the *deletion-certificate* answer too (PRV-01.1). Feature, not bug — documented in README.
- 2026-08-08 — trustops-v0.zip shipped `make_questionnaire.py` with the web-chat sandbox's absolute output path (`/home/claude/…`), which crashes anywhere else. Output path now derives from `__file__`.
- 2026-08-08 — Google 404s dated Gemini models for NEW accounts ("no longer available to new users") even though ListModels still lists them. Default is now the rolling `gemini-flash-latest` alias. Also: Gemini 3.x thinks by default and can blow a 60s read timeout — `thinkingLevel: low` + 120s timeout fixed it (the gates do the verification, not the model).
- 2026-08-24 — The `certificate` type inference read the document BODY, so "Data Retention and Deletion Standard" typed as a certificate because it mentions a "certificate of deletion", and "ISO 27001 Certification Roadmap" typed as a certificate outright. A rubber-stamped promote would have let a roadmap satisfy the certification gate — the exact T1 trap, arriving through ingestion instead. Filename now beats body, roadmap is checked first, and cert types are never auto-assigned at all.
- 2026-08-24 — `CERT_VERB` matched only certified/certificate/attestation/accredited, so "do you HOLD a SOC 2 Type II REPORT" was never classified as a certification claim and a planted injection satisfied it. Possession and assurance language now counts. Over-matching is safe here: the only consequence is demanding certificate-class evidence, which fails closed.
- 2026-08-24 — Structural tenant isolation is not the same control as scope. Isolation held perfectly while the engine happily answered "what does Globex's ISMS policy say?" from acme's corpus. No leak, but silent re-attribution of one company's controls to another. Found by the adversarial suite, not by the isolation tests — which is the argument for having both.
- 2026-08-24 — `tenants.staged_count()` counted `REVIEW.md` as a staged source, so a fully-promoted tenant showed "1 awaiting review" forever.
- 2026-08-24 — `review.py` CLI called `session.decide(args.command, args.id, ...)` — argument order is `(question_id, action)`. Every decision failed with "unknown action 'IAM-01.1'".
- 2026-08-24 — Vercel: a root `requirements.txt` makes the platform detect the repo as a single Python app ("No python entrypoint found in default locations") and refuse to deploy a static-site-plus-functions layout. Moving it to `api/requirements.txt` was not enough — explicit `builds` in `vercel.json` is the escape hatch. With `builds`, `headers`/`cleanUrls`/`trailingSlash` cannot be used alongside `routes`; put headers on a `continue: true` route instead. Also `api/*.py` globs every file in `api/`, so a shared helper module there fails the build for having no `handler` — shared code belongs in the package.
- 2026-08-24 — `pramana.vercel.app` was taken; the project's production alias is `pramana-red.vercel.app`. The bare deployment URL 302s to SSO; the alias is the public one.
- 2026-08-24 — The Supabase project (kumdsapdqzoswbkqdlqy) times out on every SQL call — free-tier projects pause after inactivity and cannot be resumed from the MCP. The waitlist code path is complete and unset; it needs `SUPABASE_URL` and `SUPABASE_ANON_KEY` in Vercel once the project is resumed. Until then the form falls back to a mail link and says plainly that nothing was stored.
- 2026-08-24 — macOS has no `timeout(1)`; use the Bash tool's own timeout. `cupsfilter` converts text to PDF for building realistic test fixtures.
