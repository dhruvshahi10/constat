# Subprocessor and Hosting Register

Two subprocessors, and no others.

Google. The Gemini API drafts answer text from a question and retrieved excerpts. Which key is used, and therefore which terms apply, depends on the mode the customer has selected: the platform's free-tier key in demo mode, the customer's own key in bring-your-own-key mode, or a paid key under a no-training commitment in managed mode.

Render. Hosts the application and the persistent disk that holds workspace data.

No analytics provider, no error-tracking provider, no email marketing provider, no content delivery network beyond the host, and no data warehouse.

Dependencies. The runtime depends on four third-party Python packages, all pinned to exact versions and installed from the same file used to build the container image, so a local environment and the deployed image resolve to an identical set. Everything else is the Python standard library, which is a deliberate reduction of supply-chain surface.

Deployment. The application runs as a single instance by design, because the run queue and the local database are single-process components. This is a documented constraint, not an accident of scale.
